# roadmap

In order, top item first.

1. **Parent-visible "questions asked today" summary.** A plain screen a parent can open: questions asked today with the child's own words, topics tried, how far each went, and wonders saved. It stays on the device, and the child can see everything the parent sees.
2. **24-hour recall prompt.** On the next visit after a finished topic, Prashna opens with one question from yesterday ("what makes the moon look like a slice?") before offering anything new.
3. **A second lesson per topic.** Moon: eclipses. Plants: how a plant eats. Cricket: percentages and strike rates. Same question-first structure, with the same branching.
4. **Guild framing.** Builders, storytellers, naturalists: the child picks a guild, and topics and Prashna's voice lean towards it (the cricket topic for builders; a "tell me the story of a raindrop" topic for storytellers).
5. **One topic in a second language.** Voice already listens in eight indian languages, but the script is english. Write one topic in hindi or kannada (questions, keywords and replies) so a child who speaks to the mic in that language gets a real reply.
