# roadmap

In order, top item first.

1. **Voice in, voice out.** Voice input with the Web Speech API and a language switch (en-IN, hi-IN, kn-IN, ta-IN, te-IN, mr-IN, bn-IN, ml-IN), plus spoken replies with speechSynthesis. Typing is the biggest barrier for an 11 year old on a phone. Where the browser lacks speech recognition, the typed input stays.
2. **Parent-visible "questions asked today" summary.** A plain screen a parent can open: questions asked today with the child's own words, topics tried, how far each went, and wonders saved. It stays on the device, and the child can see everything the parent sees.
3. **24-hour recall prompt.** On the next visit after a finished topic, Prashna opens with one question from yesterday ("what makes the moon look like a slice?") before offering anything new.
4. **A second lesson per topic.** Moon: eclipses. Plants: how a plant eats. Cricket: percentages and strike rates. Same question-first structure, with the same branching.
5. **Guild framing.** Builders, storytellers, naturalists: the child picks a guild, and topics and Prashna's voice lean towards it (the cricket topic for builders; a "tell me the story of a raindrop" topic for storytellers).
